# Employee Management System

Console application in C# demonstrating the use of core .NET Collections
(List, Dictionary, Queue, Stack, HashSet) in a company management context.

## Features
- Add employees to an onboarding queue and process them (Queue)
- Manage departments (Dictionary)
- Track active employees (List)
- Record unique skills across the company (HashSet)
- Maintain an action history log (Stack)
- Search employees by Id or Name
- Display employees by department
- Calculate average salary
- Display employee count per department

## How to Run
1. Open the solution in Visual Studio (or `dotnet run` from the project folder).
2. The app seeds sample data automatically on startup.
3. Use the numbered menu to interact with the system.
